# Каталог казахстанских вузов

Проверен 17 сентября 2026 года. В выборке **20 вузов, 82 программы, 7 городов и 17 категорий направлений**. Это база для предварительного подбора, а не полный реестр вузов или обучающая выборка с результатами поступления.

- `kazakhstan_universities.json` — основной самостоятельный файл: карточки вузов, вложенные программы, источники, словари, правила интерпретации и заметки о проверке каждой программы.
- `kazakhstan_programs.json` — экспорт для существующего `recommendation.models.Program`: JSON-массив из 100 записей. Здесь 82 уникальные программы и 18 дополнительных версий для цикла 2026 года.

Оба файла в UTF-8. Каждая программа имеет стабильный `id`, а версия определяется парой `(id, admissionYear)`. Для каждого `id` сначала выбирайте запись запрошенного года, затем запись с `admissionYear: null`. Существующий репозиторий рекомендаций уже поддерживает этот порядок. В основном файле годовые версии находятся в `programCycleOverrides`.

## Что можно использовать

Название, вуз, город, направление, интересы и поисковые теги позволяют подбирать программы по интересам и месту обучения. Коды программ заполнены, когда найдены в источнике. Языки и дисциплины заполнены только там, где проверены. Авторские аннотации, карьерные примеры, теги и рекомендуемые сильные предметы явно отделены от фактов вузов в `dataPolicy`.

Официальные источники, например: [каталог AITU](https://astanait.edu.kz/ru/bachelor), [программы и цены IITU](https://iitu.edu.kz/ru/applicants/bachelor/), [каталог ЕНУ](https://enu.kz/kz/page/university/faculties/applicants/bachelor), [программы ВКТУ](https://www.ektu.kz/educationalprograms.aspx?lang=ru). Остальные ссылки записаны у соответствующих программ. Часть источников проверена по индексированному содержанию официальных страниц; это отмечено для недоступных напрямую страниц QMU.

## Ограничения для модели

- Проверенная стоимость 2026–2027 есть у 10 программ AITU и IITU. У IITU указана стоимость первого курса: последующие курсы стоят иначе. Валюта — KZT. Цены не переносятся на 2027 год.
- Частичные пороги ЕНТ 2026–2027 есть у 8 программ КазНУ и ЕНУ. Это пороги, а не прошлогодние результаты конкурса на грант. `requirementsComplete` везде `false`: профильные предметы, минимумы по разделам, документы и дополнительные условия не полностью представлены в схеме. Для этих программ `eligibility` остается `unknown` даже при высоком ЕНТ.
- Полных маршрутов поступления, проверенных дедлайнов, доступности грантов, общежитий и студенческих клубов в этой версии нет. Модель не сможет надежно оценивать эти параметры. Неизвестная стоимость также не участвует в финансовом сравнении.
- `active: true` означает включение в каталог для исследования вариантов, а не открытый прием документов. Для обзорных записей `admissionYear: null`; сам факт существования программы не подтверждает новый набор. Особенно перепроверьте паспорта КазНАИ 2024 года и страницу программы IUTH с набором 2025–2026, отмеченные в `programEvidence`.
- У `sources.program_catalog.academicYear` недатированных страниц стоит год снимка 2026 из-за обязательного поля существующей схемы `Source`. Только источники стоимости и порогов в годовых версиях являются подтверждением конкретного цикла. Не используйте год каталога как правило приема.
- Город хранится на русском. Для казахских и английских вариантов используйте `cityAliases`; встроенная нормализация проекта знает не все региональные названия.
- `recommendedAcademicStrengths` содержит английские названия предметов. `academicStrengthAliases` в основном JSON дает варианты для нормализации ответов. Встроенная нормализация проекта покрывает только часть этого словаря.
- Каталог предназначен для content-based рекомендаций. Для обучения вероятности поступления нужны отдельные реальные результаты абитуриентов, конкурсы и квоты. `matchScore` существующей модели — совместимость, не вероятность зачисления.

## Загрузка в существующий backend

API по умолчанию читает `catalogs/kazakhstan_programs.json` через `JSONProgramRepository`. Импорт в PostgreSQL не нужен. Этот источник используется как обычными рекомендациями, так и AI-маршрутами. Файл загружается при создании приложения; после изменения каталога перезапустите backend. Docker-образ включает папку `catalogs`.

Для отдельного использования:

```python
from recommendation.repository import JSONProgramRepository
from recommendation.recommender import Recommender

repository = JSONProgramRepository()  # catalogs/kazakhstan_programs.json
programs = repository.get_programs_for_entry_year(2027)
program = repository.get_program_by_id("kz-iitu-cs", 2026)
recommender = Recommender(repository)
```

Конструктор также принимает путь к любому из двух файлов, например
`JSONProgramRepository("catalogs/kazakhstan_universities.json")`.
Путь по умолчанию привязан к расположению проекта; явно переданный относительный
путь — к рабочему каталогу процесса. Для выбора другого файла передайте репозиторий в
`create_app(program_repository=repository)`. Авторизация и анкеты API по-прежнему
используют PostgreSQL.

Файл читается и полностью проверяется при создании объекта. Для обновления данных
создайте новый объект. Ошибки JSON, схемы или дубликаты `(id, admissionYear)`
вызывают `ValueError` с путем к файлу; отсутствие файла — `FileNotFoundError`.
Методы возвращают копии `Program`; изменение результата не меняет каталог.
Версия точного года выбирается перед фильтрацией `active`/`isDemo`, поэтому
отключенная годовая версия не заменяется общей записью. Список упорядочен по `id`.

Необязательный импорт для явно подключённого `PostgreSQLProgramRepository`
(на стандартный API с JSON-каталогом не влияет), из корня проекта при настроенном `DATABASE_URL`:

```powershell
.\.venv\Scripts\python.exe -m recommendation.import_catalog catalogs/kazakhstan_programs.json
```

Импорт изменяет настроенную базу PostgreSQL. При подготовке файлов импорт в рабочую базу не выполнялся. Сам основной файл с объектом `universities` в импортер передавать нельзя — используйте плоский экспорт.

Проверить формат без подключения к базе:

```powershell
.\.venv\Scripts\python.exe -c "from pathlib import Path; from pydantic import TypeAdapter; from recommendation.models import Program; p = TypeAdapter(list[Program]).validate_json(Path('catalogs/kazakhstan_programs.json').read_text(encoding='utf-8')); print(len(p))"
```

При редактировании основного JSON обновляйте экспорт из `universities[*].programs` и `programCycleOverrides`. Не смешивайте неизвестные значения с нулями и не объявляйте маршрут поступления полным, пока не проверены все условия.
